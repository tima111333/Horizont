# Горизонт

Неофициальная художественная интерпретация истории «Интерстеллара» — одностраничный
scroll-фильм из восьми актов. Все модели, текстуры, шейдеры и звук созданы кодом
для этого сайта; кадров и музыки фильма здесь нет. Из фильма взяты только короткие
реплики героев (по одной-две на акт, в собственном переводе, с подписью, кто говорит),
остальные подписи — авторские. Все тексты — в `src/story/acts.ts`.

```
npm install
npm run dev        # http://127.0.0.1:5192
npm run build      # проверка типов + сборка в dist/
npm run preview    # http://127.0.0.1:5193
```

## Публикация на GitHub Pages

```
npm run deploy     # сборка → ветка gh-pages репозитория origin
```

Пути в сборке относительные (`base: './'`), поэтому сайт работает по адресу
`https://<пользователь>.github.io/<репозиторий>/`. В настройках репозитория
Settings → Pages → Source: *Deploy from a branch*, ветка `gh-pages`, папка `/ (root)`.

## Акты

| # | Акт | Что на экране | Как сделано |
|---|-----|---------------|-------------|
| 0 | Пыль | поле пшеницы на закате, пыльная буря, ферма | ~26 тыс. инстансов пучков в трёх LOD, ветер в вершинном шейдере, стена бури — «клубящийся» шум с подсветкой по градиенту плотности |
| 1 | Призрак | комната, полка, лучи из окна, падающая книга, полосы пыли | мягкие тени PCF, объёмные лучи маршем по лучу до глубины сцены, книга — GSAP-таймлайн, прокручиваемый скроллом |
| 2 | Эндюранс | Земля с атмосферой, старт, стыковка «Рейнджера», раскрутка кольца, двигатели | процедурная модель из 12 модулей с гриблами, PBR-обшивка, фольга, Земля — лучевой проход с аналитической сферой |
| 3 | Червоточина | Сатурн, сфера с чужим небом, пролёт сквозь горловину | лучи по метрике червоточины с цилиндрической горловиной (как у James et al., 2015), таблица из 4096 лучей на кадр |
| 4 | Миллер | вода по колено до горизонта, волна-«горы», часы замедления времени | сетка воды с большой волной, отражения, дно через воду, рябь от курсора — волновое уравнение в текстуре |
| 5 | Гаргантюа | чёрная дыра с диском, кольцо фотонов, падение | фотоны по уравнению Шварцшильда, тонкий диск с доплером; дуги над и под тенью возникают сами |
| 6 | Тессеракт | бесконечная решётка полок, нити времени, послание | инстансы, завёрнутые вокруг камеры в шейдере; курсор = положение в решётке |
| 7 | Станция | цилиндр изнутри, облака у оси, титры | внутренняя поверхность шейдером, 17 тыс. деревьев и домов инстансами, вечер к титрам |

Сквозные вещи: Lenis + ScrollTrigger (единая шкала 0..1) с пружиной поверх — щелчки колеса
не дают рывков камеры; автопросмотр: если не листать 3,5 с, фильм идёт сам (~3,3 минуты
целиком, в склейках быстрее, пока висит подпись — медленнее), любое касание колеса или
клавиш сразу отдаёт управление, кнопка внизу выключает автопросмотр совсем.
Склейки между актами через цвет,
шторки 2.39:1 в «земных» актах, постобработка (DOF, хроматическая аберрация, bloom, ACES,
грейдинг, зерно, виньетка), дыхание камеры шумом Перлина, параллакс от курсора,
кастомный курсор, шкала глав справа.

## Где что лежит

- `src/story/acts.ts` — весь сценарий: порядок и длина актов, тексты, грейдинг, цвет склеек.
- `src/scenes/*.tsx` — сцены; ракурсы задаются массивом `KEYS` в начале файла.
- `src/core/Stage.tsx` — канва, ленивое монтирование соседних актов, прогрев шейдеров,
  адаптивное разрешение (при кадре дольше ~21 мс рендер мельчает, а не дёргается).
- `src/core/scroll.ts` — прокрутка, пружина, автопросмотр (темп — `auto.pace`, пауза — `auto.idle`).
- `src/core/PostFX.tsx`, `src/core/effects.ts` — постобработка и свои эффекты.
- `src/shaders/*.glsl` — червоточина, чёрная дыра, пыль, рябь, небо.
- `src/models/*` — процедурная геометрия и текстуры (считаются в `src/workers/assets.worker.ts`).
- `src/audio/AudioManager.ts` — звук.

## Звук

Работает без файлов: каждый акт синтезируется на Web Audio (ветер, скрип дома, орган,
гул, радиопомехи с квиндар-тонами, тиканье раз в 1,25 с, морзе).
Howler владеет контекстом и мастер-громкостью, слои кроссфейдятся за 1,8 с, быстрая
прокрутка открывает фильтр. Звук включается только после клика на стартовом экране.

Свои записи (CC0 / Pixabay) подключаются без правки кода: положите файлы в `public/audio/`
и впишите их в `public/audio/manifest.json` — подробности и поисковые запросы
в `public/audio/README.md`. Детский смех в прологе появится только так: синтезировать его
правдоподобно нельзя.

## Отступления от ТЗ

- **HDRI с Poly Haven не используется.** Космических HDRI там нет, а студийные дают
  на металле рамы софтбоксов. Окружение для отражений собирается из светящихся панелей
  (солнце, планета, диск) и запекается через PMREM — отдельно для каждого акта.
- **GLB-модели не нужны.** Корабль, «Рейнджер», полка — процедурные, поэтому
  `public/models` и `public/hdri` пустые.
- Ссылка GitHub в титрах — заглушка: `REPO_URL` в `src/components/Credits.tsx`.

## Производительность

Замерено в headless Chromium на RTX 2060, 1600×900: кадр 2–10 мс во всех актах.
Тяжёлая генерация идёт в воркере; на стартовом экране все акты по очереди компилируют
шейдеры, поэтому при первом визите кнопка старта ждёт ~10–13 с (повторно браузер берёт
программы из кэша). Крупные подвисания спрятаны в затемнения склеек.
Вёрстка рассчитана на десктоп (проверено 1024–2560 px, `scripts/layout.mjs`); мобильный
адаптив убран по решению заказчика. На слабых и сенсорных устройствах остаётся облегчённый
рендер: меньше инстансов и шагов трассировки, без DOF и аберрации.

Страница сама не прокручивается: Lenis крутит отдельный невидимый слой `.scroller`.
При нативной прокрутке документа Chrome на тяжёлых кадрах сдвигал fixed-слои, и сверху
мелькала чёрная полоса — на светлом Миллере это было видно как «чёрное мерцание».

Проверка: `node scripts/shot.mjs акт:доля имя`, `scripts/tour.mjs` (прогон колесом с
замером рывков), `scripts/fps.mjs`, `scripts/audio.mjs`, `scripts/nan.mjs`.
